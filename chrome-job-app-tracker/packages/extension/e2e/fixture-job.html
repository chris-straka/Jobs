Senior Backend Engineer (Kafka)

Acme Corp is hiring a backend engineer for our event streaming platform.

You will build and operate Kafka event pipelines, Docker deployments, and distributed systems backed by Postgres and gRPC. You own services end to end: design, rollout, on-call, and post-incident review. We value engineers who write things down, measure latency, and delete code.

Requirements: five years of backend experience, deep Kafka knowledge, distributed systems fundamentals, SQL fluency, and comfort debugging production across Docker containers and Kubernetes pods. Experience with exactly-once processing and schema evolution is a plus.

Benefits: competitive salary, remote-first, annual retreat, learning budget.
